Privacy policy

Last updated: 1 November 2026

The Mole Explains Engine is a private production tool used only by the owner of the Mole Explains YouTube channel. It is not offered to the public.

What it accesses

With the channel owner's consent through Google sign-in, the tool uses the YouTube Data API and YouTube Analytics API to upload, schedule and edit the channel's own videos and to read the channel's own statistics.

What it stores

The access token is stored only on the owner's computer. Channel statistics are saved there for the owner's reports. Nothing is sold, shared with third parties or used for advertising.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact: through the Mole Explains channel.
